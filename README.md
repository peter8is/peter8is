## 🧱 Clean Architecture Approach

I follow a consistent **Clean Architecture** pattern to ensure codebase scalability, testability, and separation of concerns. Each project is organized by:
- **Presentation Layer**: Widgets, UI logic, and navigation  
- **Application Layer**: Use cases, state management (Cubit/Bloc)  
- **Domain Layer**: Entities, business logic interfaces  
- **Data Layer**: Repositories, API integration, local caching  

This architecture keeps every app modular and production-ready for future growth.
